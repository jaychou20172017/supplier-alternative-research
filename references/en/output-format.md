# Word report and CSV outputs

[中文](../output-format.md)

Primary output is `.docx`, default Chinese. Embed editable tables for candidate ranking, parameter comparisons and supplier comparisons; screenshots/external CSVs do not replace them. Links must be clickable; repeat long-table headers and keep rows intact. Provide a readable three-stage supply-chain diagram with alternative text and the boundary between evidence and inference.

Sections: scope/conclusion with input versions and gaps; technical baseline; current supplier profile; model-level candidate ranking with separate leads/exclusions; key-parameter comparison; exclusions/pending verification; defined industry segment, market basis and trends; source list with title/entity/URL or screenshot file/page, dates and supported conclusion. Company comparisons cover legal identity, registration/status, headquarters/manufacturing, formation/capital/workforce basis, certification validity, factory/patent/equipment/capacity evidence and gaps. Record PCN/EOL separately.

Full tasks also include `关键参数证据.csv` using the ledger schema. Optional candidate/supplier CSVs must share Word's IDs, order, values and evidence. Preserve full URLs, standard CSV escaping and explicit platform access limitations. A homepage/series range cannot replace exact-model evidence. Design compact readable tables rather than forcing long text into narrow columns; split parameter groups when helpful. Use available cross-platform fonts and document tooling, not machine-specific scripts. Check every page and reconcile all outputs before delivery.
