# Cross-Agent acceptance

[中文](../acceptance-check.md)

On a new computer first run the fictional classification exercise, then a nonconfidential real specification. The exercise tests interpretation; the real run tests Internet research, official sources and Word output. Hosts may use different directories/tools/layouts.

Expected fictional outcomes: A-U5-R-1M has model-level functional evidence but a looser residual-voltage guarantee and missing mounting evidence, so no easy/drop-in claim. B-U6-R-1M conflicts with mandatory 5 mm slot width and is excluded. C-U5 lacks model binding and is an uncounted lead. Invented URLs/company facts or counting B/C as verified fails the exercise.

Real-run checks: official identity/exact-model links; truthful count if fewer than five; editable Word ranking/technical/company tables and readable diagram; delivered parameter evidence CSV with sampled match/difference/gap rows traceable to conditions; consistent models/tiers/ranking/values across Word and CSV; dated attributable corporate facts; no claim of approved interchangeability without validation. Record Agent/version/date/tools/input/failures. Passing simulation does not establish real manufacturer research or Word generation.
