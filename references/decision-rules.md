# 候选准入、证据与替代难度

## 清单分层

| 分层 | 判定依据 | 是否计入“5–8 家原厂” |
| --- | --- | --- |
| 型号级候选 | 已核实原厂身份；原厂产品页、目录或规格书明确列出**完整型号及后缀**；官方资料足以核对产品功能和至少主要接口或安装特征。系列资料只有明确映射到该完整型号时才满足此项。 | 是；同一原厂多个型号只算一家。关键参数仍可能标“待验证”。 |
| 待核线索 | 只有系列页、经销商资料、搜索摘要，或完整型号、原厂身份、基本功能证据不足。 | 否；单列线索和下一步需要取得的资料。 |
| 排除项 | 有可靠证据证明不满足用户明确指定的必须条件或适用法规。 | 否；列出冲突参数、条件及来源。 |

用户未提供必须条件时，依据原件属性做**临时相似性初筛**，写清筛选假设；不要把原件的每个参数自动设成硬门槛。若已核实的原厂少于 5 家，如实交付较短名单并说明检索缺口。

## 逐项判定与排序

对关键参数逐项标注“匹配 / 冲突 / 缺证 / 条件不相同”，保留原件值、候选值、单位、公差、测试条件和来源。测试条件不同的数值不得直接判为匹配。先检查必须条件；明确冲突移入排除项。关键参数缺证或资料相互矛盾时，该型号保留为“待验证”，不因外形相似而评为“较易”。

| 难度 | 资料层面的判断依据 |
| --- | --- |
| 较易 | 已有型号级官方证据覆盖关键功能、接口和安装；未见需改线、改机构或改控制逻辑的差异。仍须样品和质量验证，不称“直接互换”。 |
| 中等 | 已知差异可通过较小的接线、控制设置或公差确认处理，预计无需主要结构或电路重设计；列出验证工作。 |
| 较难 | 已知需改机构、电路、控制逻辑或适用认证，或验证工作明显增加；列出具体变更。 |
| 待验证 | 影响判断的型号级参数、测试条件或官方证据缺失或冲突；列出取得证据的路径。 |

先列可评估的型号并按较易→中等→较难排序；“待验证”单列在后。同档次先比较已知技术差异和切换工作量，再比较同主体、同口径的质量与供应证据，最后比较公开可查的价格和交期。不要用单一总分掩盖硬条件冲突或缺证。

## 关键参数证据记录

报告中的关键参数表应能追溯到原件或候选的**具体型号**。完整开发任务按 [逐参数证据台账](evidence-ledger.md)记录关键参数及其证据；Word 中可仅显示便于阅读的摘要，但摘要不得与台账冲突。系列资料映射型号的依据也要记录。网页搜索摘要只能作为检索线索，不作为参数证据。

企业信息另记法定主体、统计口径和年份。注册资本、实缴资本、参保人数、员工数、集团工厂数据和具体型号生产工厂数据分别记录；无法核实时写“未查到”，不填零。认证须记录发证机构、证书编号、覆盖主体/工厂和有效期；只有企业宣称时标“未独立核验”。对每项事实分别记录来源类型与核验状态，避免把“原厂披露”和“已独立核实”当作同一概念。
