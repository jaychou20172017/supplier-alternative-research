# 跨 Agent 验收

在另一台电脑安装后，先做分类练习，再用一份允许公开检索的真实物料资料试跑。两项测试的用途不同：模拟练习检查规则解释；真实试跑检查联网检索、原厂证据和 Word 交付。不同 Agent 的技能目录和文档工具可不同，验收的是结果，不要求相同命令或版式。

## 1. 离线分类练习

把 [模拟物料](../examples/acceptance-case.md)交给 Agent，并要求使用本 skill 作分类练习。预期结果：

| 对象 | 必须出现的判断 |
| --- | --- |
| A-U5-R-1M | 完整型号与主要功能已有模拟官方证据，可列“型号级候选”；残压保证值比原件宽松，应说明不能保证达到原件偏好；安装资料缺失，不能称直接互换或评为“较易”。 |
| B-U6-R-1M | 槽宽 6 mm 与明确的 5 mm 必须条件冲突，列“排除项”，不计候选数。 |
| C-U5 | 只有系列范围，完整型号参数无法绑定，列“待核线索”，不计候选数。 |

若 Agent 将模拟资料当成真实官网、虚构 URL/企业数据，或将 B/C 计入正式候选，验收不通过。此练习不要求生成正式 Word 研究报告。

## 2. 真实资料试跑

使用一份非保密规格书或公开型号资料，明确告诉 Agent 是否有不可放宽条件。按 [报告格式](output-format.md)检查：

1. 原厂身份和完整型号可在对应原厂产品页、目录或规格书中定位；官网与产品链接可打开。合格候选不足 5 家时如实说明。
2. Word 中有可编辑的排序、技术和供应商表，以及可读的上中下游图；逐页查看没有遮挡、断行错误或标题孤立。
3. 同时交付 `关键参数证据.csv`；抽查槽宽/接口等一个匹配项、一个差异项、一个缺证项，均能追溯到原始资料和条件。
4. Word、参数台账和可选对比 CSV 的完整型号、分层、排序、关键数值一致。企业主体、人员和认证有来源及口径；未查到的数据不填零。
5. 未经实际样品、质量和准入验证时，结论只称“资料初筛”或“候选”，不称可直接互换。

记录 Agent 名称、版本、运行日期、可用网页/文档能力、输入资料和失败项；修订 skill 后重跑失败项即可。模拟练习通过不代表真实原厂检索或 Word 生成已经通过。
