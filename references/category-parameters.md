# 物料类别参数提示

按实际物料及应用选择字段；以下是检索提示，不是强制清单。优先使用上传资料和对应原厂规格书的术语、单位与测试条件。没有证据的字段留空。

| 类别 | 常见关键参数与替代风险 |
| --- | --- |
| 电子元器件 | 功能与引脚定义、封装/焊盘、额定与工作电压电流、精度/容差、温度范围、接口与时序、功耗、寿命、EMC、RoHS/REACH、停产状态。核对同封装是否真能引脚兼容。 |
| 运动控制 | 电机/驱动器/编码器类型、额定/峰值转矩与转速、功率、惯量、分辨率、精度、控制接口、供电、制动、轴/法兰/安装尺寸、散热、防护等级、安全认证。核对机械与控制系统兼容性。 |
| 光学 | 波长/光谱范围、透过率或反射率、焦距/数值孔径、分辨率、畸变、工作距离、光圈、镀膜、尺寸公差、环境稳定性、激光损伤阈值或传感器接口。核对测量条件。 |
| 流体 | 介质兼容性、流量/压力范围、压损、精度、响应时间、泄漏率、阀口/接头/安装尺寸、接液材料、洁净度、灭菌或生物相容性、温度、寿命。核对材料与介质、密封结构。 |
| 电源与电池 | 输入/输出电压电流、功率、效率、纹波、瞬态响应、保护、散热、尺寸与接口；电池另查化学体系、容量/能量、倍率、循环寿命、BMS、运输与安全认证。核对额定与测试条件。 |

跨类别补查：目标产品的实际使用场景、法规市场、客户指定标准、年用量、在售/停产状态、PCN/EOL 与供应连续性要求。若用户资料没有给出这些要求，不推定为筛选硬门槛；可列为待确认。
