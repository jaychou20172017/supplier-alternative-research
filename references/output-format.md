# Word 报告与 CSV 字段

## Word 研究报告（主要交付物）

输出 `.docx`，以下对比内容使用可编辑的 Word 表格，随正文一起交付，不以表格截图或外置 CSV 代替：备选原厂与型号排序、原型号与候选型号的关键技术参数横向对照、现有及候选供应商情况对比。表格中的官网和产品页链接应可点击；长表跨页时重复表头并保持单行内容完整。上中下游结构用三段式图示表达，图中字体清晰、标注证据边界，并提供简短替代文字。正文结构如下：

1. **研究范围与结论摘要**：物料、用途、资料版本、研究日期、候选数量、推荐优先级和关键缺口。
2. **原物料技术基准**：参数、原型号值、单位/条件、必须或偏好、来源位置、冲突/缺失。
3. **现有供应商档案**：法定主体与品牌关系；工商/注册、人员、经营范围、认证、工厂、专利、设备、产能、行业地位；逐项来源和状态。
4. **备选原厂排序表**：先列型号级已核实候选，另列待核线索和排除项；排名、替代难度、国产/国外、原厂与完整型号、原厂官网、官方产品页/目录/数据手册、关键差异、质量/供应能力、待验证事项。另设关键参数对比表，能看出每个关键参数的原值与候选值及“匹配/冲突/缺证/条件不相同”结论。
5. **排除与待验证**：明确不满足硬条件的型号及原因；尚缺关键证据的候选及获取证据的建议。
6. **细分领域概况**：领域定义、上下游结构、代表厂商、现有和预测规模及口径、技术与供应趋势、数据缺口。
7. **来源清单**：标题、机构/原厂/企业信息平台、URL（截图或导出资料列文件名与页码）、发布/查询日期、对应法定主体和支持的结论。原始登记/认证/专利来源、原厂披露与天眼查/企查查等第三方聚合数据分别标注；平台字段与原始来源不一致时并列记录差异。

供应商信息可采用如下字段做横向对比：法定名称、统一社会信用代码（适用时）、登记状态、总部国家或地区、制造地点、成立时间、注册/实缴资本（适用时）、人员（注明员工、参保或其他口径及年份）、经营范围、质量认证及证书有效性、工厂面积、专利、生产设备、检测设备、产能、行业地位。型号的在售/停产及 PCN/EOL 线索另列在供应连续性信息中。每项企业事实注明来源类型、主体和查询日期。一个字段无法可靠核实时写“未查到”，并在比较时保留该缺口。

**关键参数证据台账**：完整开发任务另附 `关键参数证据.csv`，字段和判定见 [逐参数证据台账](evidence-ledger.md)。报告中保留关键参数的来源提示；Word 表格、台账和可选对比 CSV 必须从同一组核查记录整理，不得用系列规格替代无法映射的型号规格。

### 紧凑版式示例

以下是**列的组织方式**，填入真实数据时按物料调整，避免把长段说明挤进窄列：

| 表格 | 建议列 |
| --- | --- |
| 候选排序 | 排名/难度｜原厂及国产/国外｜完整型号、官网和产品链接｜核心差异｜证据状态及待验证事项 |
| 技术对比 | 参数及条件｜原件值｜各候选值与判定｜型号级来源；候选多时可按机械、电气、环境等参数组拆表 |
| 供应商对比 | 品牌及法定主体｜登记与人员口径｜制造、认证和专利证据｜缺口及核验状态 |

三段式上中下游图可用 Word 图形、可编辑表格或嵌入图片表达。嵌入图片时提供替代文字，并在图旁说明归纳与直接证据的边界。不同电脑可使用可用字体和文档工具实现相同结构，不要求特定模板文件或本机脚本。

## CSV 对比表（可选辅助文件）

若另行提供 CSV，保持与 Word 报告的候选顺序、数值及证据状态一致。每行一个“原厂 + 型号”组合。首行字段建议固定为：

```csv
清单分层,排名,替代难度,原厂名称,法定主体,国产或国外,总部国家或地区,制造地点,备选完整型号,原厂官网URL,官方型号链接URL,链接类型,必须条件结论,关键技术参数对比,主要差异,认证与有效性,成立时间,注册资本,实缴资本,人员数量,工厂面积,专利数量,生产设备,检测设备,供应与质量情况,在售停产状态,PCN或EOL线索,公开价格,公开交期,待验证事项,核心来源URL,查询日期
```

参数多时再建一张参数明细 CSV，字段为“原厂,型号,参数,原物料值,候选值,单位,测试条件,差异判断,原物料来源,候选官方来源”。CSV 中的长文本用标准引号转义，URL 保留完整。不得用单一总分掩盖硬条件失败或证据缺失。

使用天眼查、企查查等平台后，可在供应商对比 CSV 末尾追加“企业信息平台,企业信息页面URL或资料文件名,平台查询日期,企业信息核验状态”等字段；若平台链接需登录才能打开，保留页面标识并在报告中写明访问限制。不要把平台参保人数直接填入未标注口径的“人员数量”。
