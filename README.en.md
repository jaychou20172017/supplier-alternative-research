# Alternative Manufacturer Research Skill
[中文](README.md) | English

Turn industrial-material specifications into a verifiable technical baseline, existing-manufacturer profile, alternative manufacturer/model comparison and industry-segment overview. Typical scope covers electronic components, motion control, optics, fluids, power supplies and batteries.

## Install and invoke
Download/clone this repository, name the folder `supplier-alternative-research`, and copy the entire folder into the host Agent's documented skills directory. Keep SKILL.md, references and examples together. No machine-specific paths, proprietary MCP account or API key is required by the instructions. The host must read attachments, search the web and generate/save `.docx`; directory discovery varies by Agent.

Example: “Use supplier-alternative-research to analyze the attached specification, research the existing manufacturer, identify 5–8 domestic/overseas alternative manufacturers and complete model numbers, compare technical and company evidence, rank substitution difficulty and explain the industry segment.”

Read [English skill instructions](SKILL.en.md), [English reference index](references/en/index.md) and [acceptance exercise](examples/acceptance-case.en.md). The original workflow defaults to a Chinese Word report with editable comparison tables and a UTF-8 parameter evidence CSV; English documentation does not silently change the output language or schema.

Corporate-information platforms can supply attributed leads, not automatic verification or shared subscriptions. No supplier contact, quotation request, order or engineering approval is performed. Test the fictional classification exercise and a nonconfidential real specification separately on a new host; do not treat one as the other.
